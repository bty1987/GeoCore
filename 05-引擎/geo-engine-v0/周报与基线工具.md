# GEO 周报与基线工具（P0-1 + P0-2）

> 建于 2026-09-30 ｜ v3.5 产品评估的新产品第 1、2 件
> 组成：`templates/基线记录表-模板.csv`（P0-2，数据底座）＋ `weekly_report.py`（P0-1，生成器）＋ `examples/`（样例）
> 定位：**把每周半天的周报整理压到 1 小时以内**；引擎上线前后都可用（手填与引擎产出同 schema）。

---

## 一、基线记录表（P0-2 · 数据底座）

**文件**：`templates/基线记录表-模板.csv` —— 复制一份填，命名建议 `台账_客户名_平台_日期.csv`。

**字段字典（14 列 = 引擎 schema 12 列 + 人工复核 2 列）**：

| 列 | 含义 | 取值 |
|---|---|---|
| run_id | 行主键＝截图文件名主干 | `日期(6位)_平台_词ID`，如 `250930_doubao_A01` |
| platform | 平台 | `doubao` / `yuanbao` / `deepseek` |
| qid | 词表编号 | A=品牌词 B=品类词 C=对比词 D=场景词（四类 40 词，执行手册 2.1） |
| query_text | 查询词原文 | 照词表填 |
| brand_mentioned | 是否提及目标品牌 | `是` / `否` / `描述性提及`（提到了但没当推荐） |
| recommend_rank | 推荐位次 | 数字（如 `3`）或 `未上榜`；品牌词留空 |
| sentiment | 倾向 | `正` / `中` / `负`（未提及留空） |
| citation_count | 引用来源数 | 数字 |
| citations | 引用来源（主要域名/链接） | 分号分隔 |
| **sources_contain_us** | 来源是否含我方 | `是` / `否`（人工复核列） |
| **competitors_mentioned** | 提及了哪些竞品 | 分号分隔（人工复核列，**必填**——竞品动态全靠它） |
| snapshot_path | 截图文件名 | 与 run_id 同名，放 `screenshots/`（即引擎 README 的 `日期_平台_查询编号.jpg`） |
| online_mode | 是否联网回答 | `是` / `否`（DeepSeek 双模式分开记） |
| collected_at | 采集时间 | `YYYY-MM-DD HH:MM:SS` |

**三条填写纪律**：①一行=一次查询，不要合并平台；②竞品列宁可多记不漏记；③截图与 run_id 一一对应，缺截图的行在 run_id 后加 `*` 并当天补。

## 二、周报生成器（P0-1 · weekly_report.py）

```bash
# 单周统计（基线/首周）
python3 weekly_report.py --this-week 台账_doubao_250930.csv

# 周环比（推荐：每周对上周）
python3 weekly_report.py --this-week 台账_doubao_250930.csv 台账_yuanbao_250930.csv \
                         --last-week 台账_doubao_250923.csv 台账_yuanbao_250923.csv

# 可选：--brand 客户名 ｜ --outdir 输出目录 ｜ --expect-full 按 40×3=120 校验完成率
```

**产出**：`output/reports/周报草稿_日期.md`，含——

1. **五个核心数字**：采集量（含完成率警告）/ 品牌词提及率（+描述性提及单列）/ 品类词提及率+最佳推荐位次 / 平均引用来源数 / 来源含我方+倾向分布
2. **周环比变化表**：新提及 ⭐ / 掉出 ⚠️ / 位次变化（未上榜正确显示）/ 引用数增减
3. **竞品动态**：被提及次数排行（前 8）
4. **需优化提问词清单**：品牌词+品类词中未提及的，直接对应下周内容工作
5. **待人工补充**：解读 / 下周动作 / 证据抽查——**三处留白是人的活，机器不编**

**两个口径锚（防漂移）**：监测口径=**40 词四类 × 3 平台**；统计规则=品牌词提及率只认 `是`（描述性提及单列不冒充）。qid→类型优先读 `queries/kongzhen-40.yaml`，没装 pyyaml 时按 A/B/C/D 前缀推断（结果一致）。

## 三、每周流程（引擎上线前）

1. 按词表手动提问＋截图（限频纪律照旧：查询间等几分钟，宁慢勿封）
2. 当天填基线记录表 CSV（或引擎跑完直接拿 `output/ledger_*.csv`）
3. 跑生成器出草稿 → 补三处留白 → 人工确认 → 对外
4. CSV 与截图按周归档（这就是效果对赌的证据链）

## 四、升级路线（占位，勿提前开发）

- 引擎 v0 落 CSV 后：本工具**零改动**接上（同 schema）
- P2-5 客户只读周报门户：消费同一份 CSV，草稿 MD 可直接喂设计产线出 PDF 样板件
- LLM 解析上线后：brand_mentioned/位次/倾向三列由人工复核转机器预填，人只抽检
