# GEO · 售前聊与 48h 预诊断作战包

> v1.0 · 2026-09-11 | 配套《GEO-合伙人演示包》《GEO服务-合伙人合作提案》使用
> 场景：意向客户第一次接触，**不做现场演示**——先售前聊 + 48 小时预诊断快照，用准备好的材料替代临场表演。

## 一、为什么"先聊"是对的（不是心虚，是策略）

1. **提案本来就这么设计**：合伙人推荐 → 我方 48 小时免费预诊断 → 报告敲门。售前聊是标准流程的第一步
2. **现场实测随机性大**：60% 查询不联网、AI 回答有波动，现场盲演可能翻车；异步准备过的快照可控、可筛选、可书面留档
3. **冲击力不减反增**：客户收到的是截图 + 书面解读，可以自己打开 App 复核、可以转发给合伙人看——"可验证"正是我们的差异化人设
4. **"我回去测了给您准确数据"是强人设不是弱表现**：敢说这句话的团队，比现场拍脑袋的可靠

## 二、30 分钟售前聊脚本（四步照走）

**第 0 步 · 开场定位（3 分钟）**

> "我们做的事一句话：让您的客户在问 AI（豆包、元宝、DeepSeek）的时候，提到您、并且把您说对。今天不推销——我先了解一下您生意的来客结构，回头免费给您出一份您品牌在 AI 里的现状快照。"

**第 1 步 · 三问诊断（15 分钟，用耳朵不用嘴巴）**

| 问 | 挖什么 |
|---|---|
| 1. "您现在新客户主要从哪来？转介绍/抖音/百度/门店各占多少？" | 获客结构与焦虑点 |
| 2. "客户找您这类服务时，一般怎么问？用什么词？" | **问法原话（快照的弹药）** |
| 3. "您最怕被谁抢生意？头三家竞品是谁？" | 竞品名单（对照的靶子） |
| 4. （可选）"您自己问过 AI 吗？它怎么说您？" | 客户认知温度 |

→ 聊完必须带走：**行业问法原话 6–8 条、品牌词写法、竞品 3 家、来客痛点**。

**第 2 步 · 留钩子（5 分钟）**

> "您这几个问题很典型。我回去用真实问法在三个平台各测一遍您和您的竞品，**48 小时内**给您一页快照，每条都有截图，您自己打开 App 就能复核。看完再决定要不要往下聊。"

**第 3 步 · 收口（5 分钟）**

- 约定看快照的时间（"后天下午您 15 分钟电话方便吗"）
- **不报价格**。被追问就："先看快照。正式方案和报价以您行业的实测数据为准，我们不报没有依据的数。"

**异议三句（背下来）**

- "你们具体怎么做？" → "监测 + 内容布局 + 语料建设，每周数据截图可验证。具体方案等快照出来、按您的实际情况定。"
- "能保证效果吗？" → "不承诺第一，承诺可验证：指标写进合同、每周截图留档。敢划线的才是真做事的。"
- "这和 SEO 有什么区别？" → "SEO 是让网页排在百度前面，我们做的是让 AI 在回答里推荐你。流量入口换地方了。"

## 三、48h 预诊断快照怎么做（约 2–3 小时工作量）

1. **问法矩阵**（从聊天原话里提取）：品牌词 2 条 / 品类词 2 条 / 场景词 2–3 条 / 竞品词 1–2 条
2. **三平台各跑一遍**：豆包 / 腾讯元宝 / DeepSeek，每条回答**完整截图**（问法可见 + 回答完整）
3. **一页解读（只做一页）**：
   - 现状：三平台提及情况小表（提到 / 没提到 / 说错）
   - 差距：竞品占位一句话定性
   - 机会：1–2 个最快见效点（例：品牌词描述纠偏，2–4 周可生效）
   - 建议：升级 L1 完整诊断能多看到什么（30–50 问法实测、竞品份额、优化路线图，7 天交付）
4. **交付**：微信发 PDF/长图 + 约 15 分钟电话解读。**这通电话才是真正的"演示"时刻**——材料全在你手里，全场没有人比你更懂这页纸

**快照结果的四种叙事（对着结果挑一句用）**

| 快照看到 | 就说 |
|---|---|
| 没提到客户 | "位置是空白的——空白意味着便宜，谁先进谁占" |
| 提到但说错 | "AI 不是不说您，是说错您——这比不说更亏" |
| 对手占榜 | "您竞品已经进场了，这个位置早卡早便宜" |
| 居然夸客户 | "品类词您在了，但长尾问题和描述准确性还有洞，快照里这几条您看" |

## 四、红线（与正式演示同等执行）

- 快照必须**真实测试、真实截图**，不 PS 不挑选到失真——这是"可验证"人设的地基
- 不承诺排名/保证收录；**空针＝自建试验田**口径，绝不说成"我们的客户"
- 引擎/自动化工具不主动提（内部产能），对外展示的是方法论、台账与截图证据链
- 预诊断免费、正式方案收费："这份快照免费，L1 诊断才谈价格"

## 五、给合伙人的分工话术（微信可直接发）

> "这次不搞现场演示，效果反而更好。你聊的时候只干三件事：问来客结构、**记客户问法的原话**、约 48 小时后看快照。快照我来出，解读电话我也上。你带回来三样就行：问法原话 6–8 条、竞品名单 3 家、客户最在意的获客痛点。"
