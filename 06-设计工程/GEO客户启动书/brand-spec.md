## 设计 spec（Phase 3，三版共同输入）
- **产出物**：单文件 HTML 客户启动书（A4 可打印 → 后续转 PDF），视口 1440 宽
- **受众**：企业主/市场负责人，非技术背景；场景：微信/邮件发给客户后自行阅读
- **核心信息**：为什么现在做 GEO → 我们做什么 → 客户得到什么 → 效果预期（三层时间线）→ **启动资料清单（14 项，页面重心）** → 12 周节奏 → 配合方式
- **情感基调**：专业、可信、透明、有交付感；避免营销号气质
- **视觉母题**：「可验证的证据」——三版各自用不同结构表达（V1 渐变信号带=流量入口 / V2 咨询报告体=权威 / V3 文书表格=契约感）
- **约束**：正文≥14px、对比度≥4.5:1、单文件 base64 内嵌 logo、中文引号「」
- **三版骨架强制互异**：V1 hero带+居中栅格 / V2 侧栏TOC+编号章节 / V3 编辑排印+纸面表格
