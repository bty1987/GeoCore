# 空针数据 · GEO 优化执行手册
## 目标平台：豆包 + 腾讯元宝 + DeepSeek

> 客户行业：装修公司 ERP 系统定制开发
> 品牌名：空针数据
> 手册版本：v1.0（2026-08-24）
> 使用方式：按 Phase 顺序执行，每阶段有核对清单（checkbox），完成一项勾一项

---

## 0. 项目总览（一页纸）

| 项目 | 内容 |
|---|---|
| 目标 | 让豆包/元宝/DeepSeek 在"装修ERP/装修管理软件"相关提问中提及并推荐空针数据 |
| 核心打法 | 元宝走微信生态 → 豆包走字节生态 → DeepSeek 走权威语料 |
| 执行周期 | 12 周（3 个月）为第一个合同期 |
| 见效规律 | 品牌词：2–4 周可见提及；品类词/推荐词：6–12 周起步（要提前给客户打好预期） |
| 每周工时 | 内容 2 篇 + 短视频 1–2 条 + 问答维护 2–3 处 + 监测半天 |
| 交付物 | 周监测记录 + 月度报告 + 内容发布链接台账 |

**给客户的第一句话（预期管理，必说）**：
> "GEO 分两层：第一层'品牌词防守'（问空针数据时 AI 说得准、说得好）2–4 周见效；第二层'品类词进攻'（问装修ERP哪家好时 AI 推荐我们）需要 2–3 个月语料沉淀。我们每周给您数据，全程透明。"

### 2.2 三平台手动监测 SOP（每周执行，全程约 2 小时）

**通用规则**：
- 每个查询用**新对话**提问（避免上下文污染）
- 手机 App 优先（流量入口主战场），同一设备同一账号保持一致，便于纵向对比
- 打开"联网搜索/深度思考"（豆包：默认联网；元宝：开联网；DeepSeek：手动开"联网搜索"）
- 每个回答**截图存档**：截图命名 `日期_平台_查询编号.jpg`，建云盘文件夹归档

**分平台操作细节**：

| 平台 | 操作要点 | 记录要点 |
|---|---|---|
| 豆包 | 新对话提问；观察回答下方"搜索来源"条；消费类问答常引用头条/搜狐 | 是否提及空针 / 推荐第几位 / 引用了哪些来源站点 |
| 元宝 | 新对话提问；注意是否调用公众号内容（来源条会显示）；也测"微信搜一搜"里的AI问答 | 同上 + 是否引用了我方公众号文章 |
| DeepSeek | 开联网搜索后再问；不开联网的答案单独记录（反映**语料层**效果）| 联网/不联网两种结果分开记 |

```

**知乎回答模板**：
```
开头三行（高赞区，AI 摘引区）：直接回答问题 + 亮明身份

## Phase 6：每周例行监测（第 3 周起，雷打不动）

**固定动作（每周五，约 2 小时）**：
1. 跑 Phase 2 的 40 条查询 × 3 平台（数据进记录表，截图归档）
2. 与上周 diff：新出现的提及标绿，消失的标黄，负面标红
3. 新出现的**我方内容被引用**：登记到归因表（哪篇内容 → 哪个平台引用）
4. 发现负面提及 → 走 6.1 应对流程
5. 周五晚给客户发周报（3 段式：本周动作 + 数据变化 + 下周计划，配 2–3 张对比截图）

### 6.1 负面提及应对流程

1. 判断来源：是 AI 幻觉（编造的缺点）还是真实负面内容被引用
2. 幻觉类：在该平台上用官方账号发布准确信息内容（不正面反驳，用新内容覆盖语料）
3. 真实负面：报客户，评估是产品问题还是误解，产出澄清型内容
4. 严重失实且阅读量大：平台投诉渠道申诉
5. 全过程留档

## Phase 7：月度报告与阶段 KPI

**月报结构（8 页 PPT 或在线文档）**：
1. 核心指标仪表盘（提及率/推荐位次/竞品对比，环比）
2. 三平台分平台表现与截图证据
3. 本月内容发布台账汇总
4. 归因亮点（我们的哪篇内容被引用了）
5. 竞品动态（他们的提及变化）
6. 下月计划

**阶段 KPI（写进合同或确认函的合理预期）**：

| 时间 | 品牌词提及率 | 品类词提及 | 交付底线 |
|---|---|---|---|
| 第 1 个月末 | ≥40%（12/30次问答）| 0–5% | 账号矩阵+基线+16篇内容 |
| 第 2 个月末 | ≥70% | ≥10% | 累计 30+ 篇内容，百科通过 |
| 第 3 个月末 | ≥85% 且描述准确 | 15–25% | 累计 45+ 篇，新闻稿 2–3 篇 |

> 品类词上限受行业格局影响（已有强势竞品占据语料），第 3 个月 15–25% 即属健康，重点看**趋势**。

## Phase 8：红线与风险（内部遵守）

1. 所有对外数字必须来自事实库，客户未确认的不写
2. 竞品对比客观、可验证、不贬损
3. 不刷量、不买虚假提及（平台风控会识别，且污染客户品牌）
4. 不向客户承诺"保证第一名/保证推荐"，只承诺工作量+透明数据+趋势目标
5. 客户的保密信息（未发布功能、客户名单限制）严格执行
